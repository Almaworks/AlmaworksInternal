# Lessons

## 2026-09-06 — Distinguish tool timeouts from execution evidence

- Status: confirmed lesson. Source: tool session, 2026-09-06.
- A timed-out tool call does not prove that the underlying executable ran, hung, or failed. Treat the execution state as unverified until an independent observation supports a conclusion.
- Do not add machine-specific speculative diagnoses. Record the exact command/context and the observable result instead.
