# Semester and Outreach export

## Accepted requirement

The user wants semester information easily exportable to Notion, including Outreach, and durable session notes. This feature is part of the active operations checklist. Implement exports without requiring a connected Notion account; a direct sync can be added separately once its destination is configured.

## Design

Provide an authenticated semester-admin export action outside the Super Admin-only Semesters module. Offer a complete semester bundle and an Outreach-only bundle. Generate CSV tables plus readable Markdown overview/notes and a manifest listing included datasets, row counts, scope, timestamp and explicit exclusions. Preserve stable source IDs for relationships; do not imply Notion CSV import automatically reconstructs relation properties. Package the files in one ZIP, with instructions to import Markdown and CSV using their respective Notion importers.

All queries use the requesting user's authenticated RLS client and verified semester-management access. Query program records by semester, and global identities/organizations only through IDs referenced by those records. Use explicit column allowlists; never export authentication identities, invitation secrets, signing material, provider authorization, storage credentials or private records unavailable to that admin. Fully paginate; any failed dataset must fail the export rather than silently producing a supposedly complete archive. Include available photo paths as references with an explicit asset limitation until binary export is implemented.

The complete bundle covers semester settings, membership/person/company information, mentor/startup semester profiles, meetings/sessions/RSVPs, Friday programs/assignments, independent mentor windows/requests, Outreach contacts/companies/opportunities/activities/import metadata, email templates and application-verified delivery history. Session Q&A/notes/newsletters must be added as those modules are implemented. Exclude raw signed message receipts; use their verified public history projection. Record exclusions in the manifest and UI.

CSV formatting must preserve Unicode, quotes, commas, newlines and nulls, neutralize formula-leading cells for spreadsheet safety, and provide deterministic columns. Archive filenames are fixed/generated by the application, never arbitrary record content. Set private no-store response headers. Test cross-semester denial, pagination, partial failures, secret-column exclusion, CSV round trips and actual ZIP extraction before browser QA.

## Verified provider references

- [Notion import documentation](https://www.notion.com/help/import-data-into-notion), checked 2026-09-08: CSV imports as databases; Markdown imports as pages, including folder ZIP import. The formats use different importer options.
- [Timeful project](https://github.com/schej-it/timeful.app/blob/main/README.md), checked 2026-09-08: the project documents a browser-plugin API for availability. Native dated availability remains the supported integrated scheduler; do not describe it as an implemented Timeful server sync.
- [Google Meet spaces.create](https://developers.google.com/workspace/meet/api/reference/rest/v2/spaces/create), checked 2026-09-08: meeting creation requires OAuth scope `meetings.space.created`. A created meeting space is not evidence of automatic breakout-room assignment; that separate capability remains under investigation.
